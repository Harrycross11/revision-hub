# Revision Hub

GCSE revision and coding practice site, as one self-contained page (`index.html`).

Live at https://harrycross11.github.io/revision-hub/

Progress and settings are saved in each visitor's own browser. Optional cloud saving (log in with an email on any device) uses a free Supabase project: run `supabase-setup.sql` in it once. Only the public Supabase URL and publishable key ever go in the page; no secret keys or AI API keys are stored in this repository.
